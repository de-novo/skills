# Clearing

Stop, look around, say where the work is. The `/wait-what` of this forest.

## What it does

Re-pitches the state of the work from the graph and the facts, in plain
words and the project's own vocabulary. The defining constraint: it reads
`understory reading` and `mycelium query --brief` first and says nothing
they do not hold.

## When to reach for it

Only a person types `/clearing`; no agent fires it. The moment is when you
have lost the thread of a long session, or when a new person joins
mid-work. For the written record instead, use
[understory](../understory/README.md).

## It's working if

- The reply fits on one screen and names one next action.
- Every claim in it can be pointed at: an item id, an assertion id, a path.

## Where it fits

A standalone over Understory and Mycelium; it changes nothing. Root map:
[How the skills fit](../../README.md#how-the-skills-fit).

## What it does to your machine

Reads two screens. Writes nothing, runs nothing else.

## Apply to a project

Nothing to plant. It uses whichever of Forester and Mycelium the project
already has.
